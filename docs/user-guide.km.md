## 1. ចាប់ផ្តើម

ចូលប្រើបានក្នុង ៤ ជំហាន។

1. ចូលគណនីដោយអ៊ីមែល ឬឈ្មោះអ្នកប្រើ និងពាក្យសម្ងាត់ដែលប្រធានក្រុមឱ្យ។
2. ពេលចូលលើកដំបូង ប្រព័ន្ធឱ្យប្តូរពាក្យសម្ងាត់។ ជ្រើសពាក្យសម្ងាត់ថ្មីដែលអ្នកចាំបាន។
3. ជ្រើសភាសា (ខ្មែរ ឬ EN) និងរបៀបភ្លឺ/ងងឹត នៅខាងលើ។
4. មានលេខកូដក្រុម? ចុច "ចូលរួមក្រុម" ហើយបញ្ចូលលេខកូដ។ បើគ្មាន សូមរង់ចាំប្រធានបន្ថែមអ្នក។

> **ចំណាំ:** ចុចរូបភ្នែកក្នុងប្រអប់ពាក្យសម្ងាត់ ដើម្បីមើលអ្វីដែលអ្នកវាយ។

<a id="daily"></a>
## 2. សរសេរ ToDo ប្រចាំថ្ងៃ

ToDo ប្រាប់ក្រុមថាថ្ងៃនេះអ្នកធ្វើអ្វី។ សរសេរក្នុងប្រអប់តែមួយ នៅទំព័រដើម ឬ "ToDo ប្រចាំថ្ងៃ"។

1. បន្ទាត់ទី ១ ជាឈ្មោះគម្រោង ឬចំណងជើង។ វាមិនមែនជាកិច្ចការទេ។
2. បន្ទាត់បន្ទាប់ជាកិច្ចការ មួយបន្ទាត់ក្នុងមួយកិច្ចការ ចាប់ផ្តើមដោយ "-"។
3. ចង់ប្រាប់ថាធ្វើបានប៉ុន្មាន? សរសេរ "- 80%" នៅចុងបន្ទាត់។
4. ធ្វើរួចហើយ? ដាក់ [x] ឬ 100%។
5. មើលប្រអប់ "មើលជាមុន" ក្រោមអក្សរ ដើម្បីពិនិត្យ រួចចុច "បង្ហោះ" (ឬ Ctrl+Enter)។

**គំរូ**

```
គម្រោងវេបសាយ
- រចនាទំព័រ Login - 80%
- សរសេរសៀវភៅណែនាំ
- [x] រៀបចំ Database
```

**ខុស**

```
- រចនាទំព័រ Login
- សរសេរសៀវភៅ
```

**ត្រូវ**

```
គម្រោងវេបសាយ
- រចនាទំព័រ Login
- សរសេរសៀវភៅ
```

បន្ទាត់ទី ១ ត្រូវបានយកជាឈ្មោះគម្រោង។ បើសរសេរកិច្ចការនៅទីនោះ វាបាត់ពីបញ្ជី។

**ខុស**

```
គម្រោងវេបសាយ
- រចនា 80%
```

**ត្រូវ**

```
គម្រោងវេបសាយ
- រចនា - 80%
```

ត្រូវមានសញ្ញា "-" មុនលេខ។ ឬសរសេរ "(80%)" ក៏បាន។

**ខុស**

```
គម្រោងវេបសាយ
- រចនា 80% រួចសរសេរបន្ត
```

**ត្រូវ**

```
គម្រោងវេបសាយ
- រចនាបន្ត - 80%
```

ភាគរយត្រូវនៅចុងបំផុតនៃបន្ទាត់ ទើបប្រព័ន្ធអាន។

**ខុស**

```
គម្រោងវេបសាយ
- រចនា, សរសេរ, តេស្ត
```

**ត្រូវ**

```
គម្រោងវេបសាយ
- រចនា
- សរសេរ
- តេស្ត
```

មួយបន្ទាត់ ក្នុងមួយកិច្ចការ ទើបធីក និងគិតភាគរយបាន។

> **ចំណាំ:** លេខរៀង "1." "2." ក៏ត្រូវបានអានជាកិច្ចការដែរ។

> **ចំណាំ:** ភាគរយនៃ ToDo = មធ្យមភាគនៃកិច្ចការទាំងអស់ (ធ្វើរួច = ១០០%)។

<a id="fix"></a>
## 3. ខុស? កែបាន

អ្នកអាចកែ ToDo ដែលបានបង្ហោះ។ មិនបាច់លុបហើយសរសេរថ្មីទេ។

1. ចុចរូបខ្មៅដៃ នៅជ្រុងខាងស្តាំនៃ ToDo របស់អ្នក។
2. កែអត្ថបទ មើលលទ្ធផលក្នុង "មើលជាមុន" រួចចុច "រក្សាទុក"។
3. កិច្ចការដែលអ្នកបានធីករួច នៅតែធីក ប្រសិនបើអត្ថបទរបស់វាមិនប្តូរ។
4. ចង់ធីក ឬដកធីក? ចុចលើកិច្ចការនោះក្នុងបញ្ជី។
5. ធ្វើអស់ហើយ? ចុច "បញ្ជាក់ថាបានធ្វើរួច" ដើម្បីឱ្យប្រធានត្រួតពិនិត្យ។

> **ចំណាំ:** ពេលប្រធានអនុម័តហើយ មានតែប្រធានដែលកែបាន។

> **ចំណាំ:** ចង់លុបទាំងមូល? ចុចរូបធុងសំរាម។

<a id="tasks"></a>
## 4. កិច្ចការដែលបានចាត់ឱ្យ

ប្រធានចាត់កិច្ចការឱ្យអ្នក ហើយអ្នកប្រាប់ថាធ្វើបានប៉ុន្មាន។

1. បើកផ្ទាំង "កិច្ចការ" ដើម្បីឃើញកិច្ចការរបស់អ្នក និងថ្ងៃកំណត់។
2. ចុច "ចាប់ផ្តើម" ពេលចាប់ផ្តើមធ្វើ។
3. រំកិលរបារ "វឌ្ឍនភាព" ឬចុច 25% 50% 75%។ ប្រព័ន្ធរក្សាទុកដោយខ្លួនឯង។
4. ធ្វើរួច? ចុច "រួចរាល់" (១០០%) វានឹងទៅរង់ចាំប្រធានត្រួតពិនិត្យ។
5. រង់ចាំប្រធានអនុម័ត។ ពេលអនុម័តរួច កិច្ចការត្រូវបិទ។

> **ចំណាំ:** ពណ៌ក្រហម = ហួសកំណត់។ សួរសំណួរដោយដាក់មតិយោបល់ក្នុងកិច្ចការ។

<a id="team"></a>
## 5. កិច្ចការរួម (ទាំងអស់គ្នា)

កិច្ចការតែមួយ ដែលសមាជិកម្នាក់ៗត្រូវធ្វើ ឧទាហរណ៍ "ដំឡើងកម្មវិធី"។

1. ប្រធានជ្រើស "ទាំងអស់គ្នា" ឬ "ជ្រើសរើស" ពេលកំណត់កិច្ចការថ្មី។
2. កាតតែមួយបង្ហាញវឌ្ឍនភាពរួម (មធ្យមភាគ) និងផ្នែករបស់ម្នាក់ៗ។
3. អ្នករំកិលបានតែវឌ្ឍនភាពរបស់អ្នកផ្ទាល់។ ប្រធានកែបានរបស់គ្រប់គ្នា។
4. ចុច "មើលជាកិច្ចការនីមួយៗ" ដើម្បីមើលចំណាំ មតិយោបល់ និងថ្ងៃកំណត់របស់ម្នាក់ៗ។

<a id="talk"></a>
## 6. មតិយោបល់ និងប្រតិកម្ម

1. ចុច "មតិយោបល់" ក្រោមកិច្ចការ ឬ ToDo ដើម្បីសរសេរ។ Ctrl+Enter ដើម្បីផ្ញើ។
2. កែ ឬលុបមតិរបស់អ្នកបាន។ ប្រធានលុបមតិអ្នកដទៃបាន តែកែមិនបាន។
3. ចុចរូបញញឹម ដើម្បីដាក់ប្រតិកម្មលើ ToDo។ ចុចម្តងទៀតដើម្បីដក។
4. រូបកណ្ដឹងខាងលើ ប្រាប់ពីការងារ និងមតិថ្មី។

<a id="leader"></a>
## 7. សម្រាប់ប្រធានក្រុម

1. បង្កើតក្រុម រួចបន្ថែមសមាជិក ("បន្ថែមសមាជិក")។ ពាក្យសម្ងាត់បណ្តោះអាសន្នបង្ហាញតែម្តង ដូច្នេះចម្លងវាភ្លាម។
2. ចាត់កិច្ចការ៖ ប៊ូតុង "កំណត់កិច្ចការថ្មី"។ ជ្រើសម្នាក់ ជ្រើសរើស ឬទាំងអស់គ្នា។
3. ប្តូរថ្ងៃកំណត់ដោយចុចលើថ្ងៃ។ ប្តូរអ្នកទទួលដោយចុច "ប្តូរអ្នកទទួល"។
4. ពិនិត្យ និងអនុម័ត ToDo និងកិច្ចការដែលមានស្លាក "រង់ចាំត្រួតពិនិត្យ"។
5. បើកផ្ទាំង "របាយការណ៍" ដើម្បីបោះពុម្ពសេចក្តីសង្ខេបបង្ហាញគ្រូ។

<a id="help"></a>
## 8. បញ្ហាញឹកញាប់

**ភ្លេចពាក្យសម្ងាត់?**

ប្រាប់ប្រធានក្រុម។ គាត់បង្កើតពាក្យសម្ងាត់បណ្តោះអាសន្នថ្មីឱ្យអ្នក។

**ចូលមិនបាន?**

ពិនិត្យអ៊ីមែល ឬឈ្មោះអ្នកប្រើ និងពាក្យសម្ងាត់ (មើលអក្សរធំតូច)។ បើនៅតែមិនបាន ប្រាប់ប្រធានក្រុម។

**មិនអាចសរសេរ ឬកែអ្វីទេ?**

អ្នកប្រហែលជា "អ្នកមើល" ដែលអានបានតែប៉ុណ្ណោះ។ ឬគណនីប្រធានក្រុមផុតកំណត់ ក្រុមក្លាយជាមើលតែប៉ុណ្ណោះ។

**ToDo ត្រូវបានអនុម័តហើយ ចង់កែ?**

ប្រាប់ប្រធានក្រុម។ មានតែប្រធានដែលកែបាន។

**ភាគរយ ToDo ខុស?**

សរសេរ "- 80%" នៅចុងបន្ទាត់ ហើយមើល "មើលជាមុន" មុនបង្ហោះ។
