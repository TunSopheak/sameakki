## 1. ចាប់ផ្តើម

អ្នកអាចចាប់ផ្តើមប្រើបានក្នុង ៤ ជំហានសាមញ្ញ។

1. ចូលគណនីដោយអ៊ីមែល ឬឈ្មោះអ្នកប្រើ និងពាក្យសម្ងាត់ដែលប្រធានក្រុមបានឱ្យអ្នក។
2. ពេលចូលលើកដំបូង ប្រព័ន្ធនឹងសុំឱ្យអ្នកប្តូរពាក្យសម្ងាត់។ សូមជ្រើសពាក្យសម្ងាត់ថ្មីដែលអ្នកចាំបាន។
3. ចង់ប្តូរភាសា? ចុចរូបទង់នៅជ្រុងខាងលើស្តាំ ហើយជ្រើស «ខ្មែរ» ឬ «English»។ ប៊ូតុងនៅក្បែរនោះប្តូររបៀបភ្លឺ ឬងងឹត។
4. មានលេខកូដក្រុម? ចុច «ចូលរួមក្រុម» ហើយបញ្ចូលលេខកូដ។ បើគ្មាន សូមរង់ចាំប្រធានក្រុមបន្ថែមអ្នក។

> **ចំណាំ:** ចុចរូបភ្នែកក្នុងប្រអប់ពាក្យសម្ងាត់ ដើម្បីមើលអ្វីដែលអ្នកបានវាយ។

> **ចំណាំ:** ចង់ប្តូររូបតំណាង? ចុចឈ្មោះរបស់អ្នកខាងក្រោមឆ្វេង រួចចុច «ប្តូររូបតំណាង»។ មាន ៣០ រូប រួមទាំងជនជាតិខ្មែរគ្រប់សម័យកាល ចាប់ពីនគរភ្នំ អង្គរ រហូតដល់សម័យថ្មី។

> **ចំណាំ:** ទ្រាំវាយអ៊ីមែលវែងមិនបាន? ចុចឈ្មោះរបស់អ្នកខាងក្រោមឆ្វេង បើក «ការកំណត់ផ្ទាល់ខ្លួន» ហើយដាក់ «ឈ្មោះអ្នកប្រើ» ខ្លីៗ (ឧទាហរណ៍ sopheak)។ លើកក្រោយអ្នកអាចចូលដោយឈ្មោះនេះជំនួសអ៊ីមែល។ ឈ្មោះនេះមិនអាចដូចអ្នកដទៃទេ។

## 2. សរសេរ ToDo ប្រចាំថ្ងៃ

ToDo ប្រាប់ក្រុមថាថ្ងៃនេះអ្នកធ្វើអ្វី។ សរសេរក្នុងប្រអប់តែមួយ នៅទំព័រ «ទិដ្ឋភាពទូទៅ» ឬ «ToDo ប្រចាំថ្ងៃ»។

1. សរសេរ «ចំណុចគោល» មួយក្នុងមួយបន្ទាត់ ដោយមិនដាក់ «-»។ វាអាចជាឈ្មោះគម្រោង ឬផ្នែកមួយនៃគម្រោង។
2. ក្រោមវា សរសេរចំណុចតូចៗដែលត្រូវធីក។ ចាប់ផ្តើមដោយ «-» មួយបន្ទាត់ក្នុងមួយចំណុច។
3. មិនចង់បានចំណុចគោលទេ? សរសេរតែបន្ទាត់ «-» ប៉ុណ្ណោះ។ បន្ទាត់នីមួយៗនឹងក្លាយជាកិច្ចការដែលអាចធីកបាន។
4. ធ្វើគម្រោងតែមួយ តែមានច្រើនផ្នែក? សូមដាក់ចំណុចគោលបន្ថែម។ កិច្ចការក្រោមចំណុចគោលនីមួយៗនឹងត្រូវដាក់ជាក្រុម។
5. ចង់ប្រាប់ថាធ្វើបានប៉ុន្មាន? សរសេរ «- 80%» នៅចុងបន្ទាត់។ ធ្វើរួចហើយ? ដាក់ [x] ឬ 100%។
6. ពេលអ្នកវាយ ប្រអប់ «មើលជាមុន» នឹងលេចឡើងក្រោមអក្សរ។ សូមពិនិត្យឱ្យត្រូវ រួចចុច «បង្ហោះ ToDo» (ឬចុច Ctrl+Enter)។

**គំរូ**

```
គម្រោងបញ្ចប់ការសិក្សា
វេបសាយ
- រចនាទំព័រ Login - 80%
- [x] រៀបចំ Database
កម្មវិធីទូរស័ព្ទ
- សាងសង់ទំព័រដើម
```

**ខុស**

```
វេបសាយ
- រចនា 80%
```

**ត្រូវ**

```
វេបសាយ
- រចនា - 80%
```

ត្រូវមានសញ្ញា «-» មុនលេខ។ ឬសរសេរ «(80%)» ក៏បាន។

**ខុស**

```
វេបសាយ
- រចនា 80% រួចសរសេរបន្ត
```

**ត្រូវ**

```
វេបសាយ
- រចនាបន្ត - 80%
```

ភាគរយត្រូវនៅចុងបំផុតនៃបន្ទាត់ ទើបប្រព័ន្ធអានបាន។

**ខុស**

```
វេបសាយ
- រចនា, សរសេរ, តេស្ត
```

**ត្រូវ**

```
វេបសាយ
- រចនា
- សរសេរ
- តេស្ត
```

មួយបន្ទាត់ត្រូវមានតែមួយកិច្ចការ ដើម្បីឱ្យធីក និងគិតភាគរយបាន។

> **ចំណាំ:** លេខរៀង «1.» «2.» ក៏ត្រូវបានអានជាកិច្ចការដែរ។

> **ចំណាំ:** ភាគរយរបស់ ToDo គឺមធ្យមភាគនៃកិច្ចការទាំងអស់ (កិច្ចការដែលធ្វើរួចរាប់ជា ១០០%)។

## 3. ខុស? អាចកែបាន

អ្នកអាចកែ ToDo ដែលបានបង្ហោះ។ មិនចាំបាច់លុបហើយសរសេរថ្មីទេ។

1. ចុចរូបខ្មៅដៃនៅជ្រុងខាងលើស្តាំនៃ ToDo របស់អ្នក (ក្នុងទំព័រ «ToDo ប្រចាំថ្ងៃ»)។
2. កែអត្ថបទ មើលលទ្ធផលក្នុង «មើលជាមុន» រួចចុច «រក្សាទុក»។
3. កិច្ចការដែលអ្នកបានធីករួច នៅតែធីក ប្រសិនបើអត្ថបទរបស់វាមិនប្តូរ។
4. ចង់ធីក ឬដកធីក? ចុចលើកិច្ចការនោះក្នុងបញ្ជី។
5. ពេលធីកគ្រប់កិច្ចការ ToDo នឹងរួចដោយស្វ័យប្រវត្តិ។ ឬអ្នកអាចចុច «បញ្ជាក់ថាបានធ្វើរួច» ដើម្បីឱ្យប្រធានក្រុមមកពិនិត្យ។

> **ចំណាំ:** ពេលប្រធានក្រុមអនុម័តហើយ ToDo នឹងត្រូវចាក់សោ គ្មានអ្នកណាកែបានទេ។ បើត្រូវកែ ប្រធានក្រុមអាចចុច «បើកឡើងវិញដើម្បីកែ»។

> **ចំណាំ:** ចង់លុបទាំងមូល? ចុចរូបធុងសំរាម។

## 4. កិច្ចការដែលបានចាត់ឱ្យអ្នក

ប្រធានក្រុមចាត់កិច្ចការឱ្យអ្នក ហើយអ្នកប្រាប់ក្រុមថាធ្វើបានប៉ុន្មាន។

1. បើកទំព័រ «កិច្ចការ» ដើម្បីមើលកិច្ចការរបស់អ្នក និងថ្ងៃកំណត់។
2. ចុច «ចាប់ផ្តើម» ពេលអ្នកចាប់ផ្តើមធ្វើ។
3. រំកិលរបារ «វឌ្ឍនភាព» ឬចុច 25% 50% 75%។ ប្រព័ន្ធរក្សាទុកដោយខ្លួនឯង មិនចាំបាច់ចុចរក្សាទុកទេ។
4. ធ្វើរួចហើយ? ចុច «រួចរាល់» (១០០%) ឬ «ធ្វើរួច ផ្ញើឱ្យពិនិត្យ»។ កិច្ចការនឹងទៅរង់ចាំប្រធានក្រុមពិនិត្យ។
5. បើត្រឹមត្រូវ ប្រធានក្រុមនឹងអនុម័ត ហើយកិច្ចការត្រូវចាក់សោ។ បើមិនទាន់ត្រូវ គាត់ចុច «ស្នើសុំកែ» ជាមួយមូលហេតុ ហើយកិច្ចការត្រឡប់ទៅ «កំពុងធ្វើ»។ អ្នកនឹងទទួលដំណឹង សូមកែ រួចផ្ញើម្តងទៀត។

> **ចំណាំ:** ពណ៌ក្រហមមានន័យថាហួសកំណត់។ ចង់សួរសំណួរ សូមសរសេរមតិយោបល់ក្នុងកិច្ចការ។

> **ចំណាំ:** ចង់ដឹងថាថ្ងៃនេះមានអ្វីត្រូវធ្វើ? ទំព័រ «ទិដ្ឋភាពទូទៅ» មានជួរ «ថ្ងៃនេះ» បង្ហាញចំនួន «ខ្ញុំម្នាក់ឯង» «ខ្ញុំរួមក្រុម» និង «ហួសកំណត់»។ ចុចលើវា ដើម្បីបើកទំព័រកិច្ចការដែលត្រងរួចហើយ។

> **ចំណាំ:** ទំព័រ «កិច្ចការ» និង «ToDo ប្រចាំថ្ងៃ» មានតម្រងដូចគ្នា៖ ទាំងអស់ ឬខ្ញុំម្នាក់ឯង គ្រប់ពេល ថ្ងៃនេះ ឬជ្រើសថ្ងៃ និងស្ថានភាព។ ក្នុងទំព័រ «កិច្ចការ» ចុច «តម្រងបន្ថែម» សម្រាប់សមាជិក ប្រភេទ និងលំដាប់។

> **ចំណាំ:** ពិពណ៌នាវែង? ចុច «បង្ហាញបន្ថែម» ក្រោមកិច្ចការ ដើម្បីមើលទាំងអស់។

## 5. កិច្ចការរួម (ទាំងអស់គ្នា)

កិច្ចការតែមួយដែលសមាជិកម្នាក់ៗត្រូវធ្វើ ឧទាហរណ៍ «ដំឡើងកម្មវិធី»។

1. ពេលកំណត់កិច្ចការថ្មី ប្រធានក្រុមជ្រើស «ទាំងអស់គ្នា» ឬ «ជ្រើសរើស»។
2. កាតតែមួយបង្ហាញវឌ្ឍនភាពរួមរបស់ក្រុម (មធ្យមភាគ) និងផ្នែករបស់ម្នាក់ៗ។
3. អ្នករំកិលបានតែវឌ្ឍនភាពរបស់ខ្លួនឯង។ ប្រធានក្រុមកែបានរបស់គ្រប់គ្នា។
4. ចុច «មើលជាកិច្ចការនីមួយៗ» ដើម្បីមើលកំណត់ចំណាំ មតិយោបល់ និងថ្ងៃកំណត់របស់ម្នាក់ៗ។

<a id="talk"></a>
## 6. មតិយោបល់ និងប្រតិកម្ម

1. ចុច «មតិយោបល់» ក្រោមកិច្ចការ ឬ ToDo រួចសរសេរក្នុងប្រអប់។ ចុចព្រួញនៅខាងស្តាំ (ឬ Ctrl+Enter) ដើម្បីផ្ញើ។
2. អ្នកអាចកែ ឬលុបមតិរបស់ខ្លួនឯង។ ប្រធានក្រុមអាចលុបមតិរបស់អ្នកដទៃ ប៉ុន្តែមិនអាចកែបានទេ។
3. ចុចរូបញញឹមក្បែរ ToDo ដើម្បីដាក់ប្រតិកម្ម។ ចុចម្តងទៀតដើម្បីដកចេញ។
4. រូបកណ្ដឹងនៅខាងលើ ប្រាប់អ្នកពីកិច្ចការ និងមតិយោបល់ថ្មី។ ពេលអ្នកចុចអាន ការជូនដំណឹងនោះនឹងបាត់ពីបញ្ជី ដូច្នេះបញ្ជីមានតែអ្វីដែលអ្នកមិនទាន់អាន។

## 7. Streak និងការ Poke

Streak គឺចំនួនថ្ងៃជាប់គ្នាដែលអ្នកបង្ហោះ ToDo ប្រចាំថ្ងៃ។ វាជួយឱ្យអ្នកមានទម្លាប់ល្អ ហើយក្រុមឃើញថាអ្នកណាខំប្រឹង។

1. បង្ហោះ ToDo យ៉ាងតិចម្តងក្នុងមួយថ្ងៃ (ម៉ោងកម្ពុជា)។ ថ្ងៃនោះនឹងរាប់ ហើយ Streak កើនមួយថ្ងៃ។
2. Streak របស់អ្នកបង្ហាញលើប្រអប់បង្ហោះ (🔥 ៥ ថ្ងៃជាប់គ្នា)។ ចំណាត់ថ្នាក់របស់ក្រុមនៅទំព័រ «ទិដ្ឋភាពទូទៅ»។
3. បើខាន ១ ថ្ងៃពេញ Streak ត្រឡប់ទៅ ០។ ប៉ុន្តែបើថ្ងៃនេះមិនទាន់ផុត អ្នកនៅមានពេលបង្ហោះដើម្បីរក្សាវា។
4. ឃើញសមាជិកមិនទាន់បង្ហោះថ្ងៃនេះ? ចុច «Poke» ក្បែរឈ្មោះគាត់។ គាត់នឹងទទួលការជូនដំណឹង (និងសារ Telegram បើគាត់បានភ្ជាប់)។
5. អ្នក Poke មនុស្សតែមួយបានម្តងក្នុងមួយថ្ងៃ។ ពេលគាត់បង្ហោះរួច ប៊ូតុង Poke នឹងបាត់។
6. ចង់ទទួលការជូនដំណឹងក្នុង Telegram? ចុច «ភ្ជាប់ Telegram» លើកាតចំណាត់ថ្នាក់ (ឬក្នុង «ការកំណត់ផ្ទាល់ខ្លួន») រួចចុច Start ក្នុង Telegram ម្តង។ មុខងារនេះដំណើរការបានតែពេលប្រព័ន្ធបានដំឡើង bot។
7. ក្រោយភ្ជាប់ អ្នកនឹងទទួលការ Poke និងការជូនដំណឹងដូចរូបកណ្ដឹង (កិច្ចការថ្មី ការអនុម័ត មតិយោបល់) ជាភាសាដែលអ្នកកំពុងប្រើ។ ចង់បានតែការ Poke? សូមដកធីក «ផ្ញើការជូនដំណឹងផ្សេងៗមក Telegram ផង»។

> **ចំណាំ:** Streak រាប់តាមថ្ងៃដែលអ្នកបង្ហោះពិតប្រាកដ។ អ្នកមើលមិនមាន Streak ទេ។

## 8. សម្រាប់ប្រធានក្រុម

1. បង្កើតក្រុម រួចចុច «បន្ថែមសមាជិក»។ ពាក្យសម្ងាត់បណ្តោះអាសន្នបង្ហាញតែម្តង ដូច្នេះសូមចម្លងវាភ្លាម។
2. ចាត់កិច្ចការដោយចុច «កំណត់កិច្ចការថ្មី» ហើយជ្រើស «ម្នាក់» «ជ្រើសរើស» ឬ «ទាំងអស់គ្នា»។
3. មានកិច្ចការច្រើន? ចុច «នាំចូលកិច្ចការ» ក្នុងទំព័រ «កិច្ចការ» រួចដាក់តារាងពី Google Sheets ឬ Excel (ឬជ្រើសឯកសារ CSV)។ មួយជួរដេកគឺមួយកិច្ចការ។
4. តារាងត្រូវមានយ៉ាងតិចជួរឈរ Task title និង Due date។ ជួរឈរផ្សេងៗ (Module, Assign to, Members, Priority, Start date, Due time, Details) ជាជម្រើស។ ចុច «ទាញយកគំរូ» ដើម្បីបានទម្រង់ត្រឹមត្រូវ។
5. ប្រព័ន្ធបង្ហាញលទ្ធផលជាមុន ហើយរំលងជួរដែលមានបញ្ហា។ បន្ទាប់មកចុចប៊ូតុងនាំចូល ដើម្បីបង្កើតកិច្ចការទាំងអស់ក្នុងពេលតែមួយ។
6. ចង់ប្តូរថ្ងៃកំណត់? ចុចលើថ្ងៃនោះ។ ចង់ប្តូរអ្នកទទួល? ចុច «ប្តូរអ្នកទទួល»។
7. ពិនិត្យកិច្ចការដែលមានស្លាក «រង់ចាំត្រួតពិនិត្យ»៖ ចុច «អនុម័ត» ឬ «ស្នើសុំកែ» (ត្រូវសរសេរមូលហេតុ)។ មានច្រើន? ចុច «អនុម័តទាំងអស់»។ កិច្ចការដែលអនុម័តរួចត្រូវចាក់សោ។ បើត្រូវកែ សូមចុច «បើកឡើងវិញដើម្បីកែ»។
8. ចង់កែចំណងជើង ពិពណ៌នា ប្រភេទ ឬភាពសំខាន់? ចុចរូបខ្មៅដៃលើកាតកិច្ចការ។ កិច្ចការរួមនឹងប្តូរសម្រាប់មនុស្សគ្រប់គ្នា។ ចុចរូបអំពូលក្នុងទំព័រកិច្ចការ ដើម្បីមើល «របៀបដំណើរការកិច្ចការ»។
9. បើកទំព័រ «របាយការណ៍» រួចចុច «បោះពុម្ព / PDF» ដើម្បីបានសេចក្តីសង្ខេបសម្រាប់បង្ហាញគ្រូ។

## 9. សំណួរញឹកញាប់

**ភ្លេចពាក្យសម្ងាត់?**

សូមប្រាប់ប្រធានក្រុម។ គាត់នឹងបង្កើតពាក្យសម្ងាត់បណ្តោះអាសន្នថ្មីឱ្យអ្នក។

**ចូលគណនីមិនបាន?**

សូមពិនិត្យអ៊ីមែល ឬឈ្មោះអ្នកប្រើ និងពាក្យសម្ងាត់ (ប្រយ័ត្នអក្សរធំ និងអក្សរតូចក្នុងពាក្យសម្ងាត់)។ បើនៅតែមិនបាន សូមប្រាប់ប្រធានក្រុម។

**មិនអាចសរសេរ ឬកែអ្វីទេ?**

អ្នកប្រហែលជា «អ្នកមើល» ដែលអានបានតែប៉ុណ្ណោះ។ ឬកញ្ចប់របស់ប្រធានក្រុមបានផុតកំណត់ ដូច្នេះក្រុមមើលបានតែប៉ុណ្ណោះ។

**ToDo ត្រូវបានអនុម័តហើយ តែចង់កែ?**

សូមប្រាប់ប្រធានក្រុម។ គាត់ត្រូវចុច «បើកឡើងវិញដើម្បីកែ» ជាមុន អ្នកទើបកែបាន។

**ភាគរយរបស់ ToDo ខុស?**

សូមសរសេរ «- 80%» នៅចុងបន្ទាត់ ហើយមើល «មើលជាមុន» មុនបង្ហោះ។

**មិនទទួលសារ Telegram?**

សូមពិនិត្យថា «ការកំណត់ផ្ទាល់ខ្លួន» បង្ហាញ «បានភ្ជាប់»។ ប្រសិនបើអ្នកបាន block bot សូមលែង block រួចភ្ជាប់ម្តងទៀត។
