## 1. ចាប់ផ្តើម

ចាប់ផ្តើមប្រើបានក្នុង ៤ ជំហានសាមញ្ញ។

1. ចូលគណនីដោយអ៊ីមែល ឬឈ្មោះអ្នកប្រើ និងពាក្យសម្ងាត់ដែលប្រធានក្រុមឱ្យ។
2. ពេលចូលលើកដំបូង ប្រព័ន្ធឱ្យប្តូរពាក្យសម្ងាត់។ ជ្រើសពាក្យសម្ងាត់ថ្មីដែលអ្នកចាំបាន។
3. ចង់ប្តូរភាសា? ចុចរូបទង់នៅជ្រុងខាងលើស្តាំ ហើយជ្រើស "ខ្មែរ" ឬ "English"។ ក្បែរនោះមានប៊ូតុងប្តូរពណ៌ភ្លឺ/ងងឹតដែរ។
4. ទ្រាំវាយអ៊ីមែលវែងមិនបាន? ចុចរូបភាពរបស់អ្នកខាងក្រោមឆ្វេង បើក "ការកំណត់របស់ខ្ញុំ" រួចដាក់ "ឈ្មោះអ្នកប្រើ" ខ្លីៗ (ឧ. sopheak)។ លើកក្រោយចូលដោយឈ្មោះនេះជំនួសអ៊ីមែលបាន។ ឈ្មោះមិនអាចដូចអ្នកដទៃ។
5. មានលេខកូដក្រុម? ចុច "ចូលរួមក្រុម" ហើយបញ្ចូលលេខកូដ។ បើគ្មាន សូមរង់ចាំប្រធានក្រុមបន្ថែមអ្នក។

> **ចំណាំ:** ចុចរូបភ្នែកក្នុងប្រអប់ពាក្យសម្ងាត់ ដើម្បីមើលអ្វីដែលអ្នកវាយ។

<a id="daily"></a>
## 2. សរសេរ ToDo ប្រចាំថ្ងៃ

ToDo ប្រាប់ក្រុមថាថ្ងៃនេះអ្នកធ្វើអ្វី។ សរសេរក្នុងប្រអប់តែមួយ នៅទំព័រដើម ឬ "ToDo ប្រចាំថ្ងៃ"។

1. សរសេរ "ចំណុចគោល" មួយក្នុងមួយបន្ទាត់ (មិនដាក់ "-") ឧទាហរណ៍ ឈ្មោះគម្រោង ឬផ្នែកមួយនៃគម្រោង។
2. ក្រោមវា រាយចំណុចតូចៗដែលត្រូវធីក។ ចាប់ផ្តើមដោយ "-" មួយបន្ទាត់ក្នុងមួយចំណុច។
3. មិនចង់បានចំណុចគោលទេ? សរសេរតែបន្ទាត់ "-" ប៉ុណ្ណោះ។ បន្ទាត់នីមួយៗក្លាយជាកិច្ចការដែលអាចធីកបាន។
4. ធ្វើគម្រោងតែមួយ តែមានច្រើនផ្នែក? ដាក់ចំណុចគោលបន្ថែម។ កិច្ចការនៅក្រោមចំណុចនីមួយៗត្រូវដាក់ជាក្រុមរួមគ្នា។
5. ចង់ប្រាប់ថាធ្វើបានប៉ុន្មាន? សរសេរ "- 80%" នៅចុងបន្ទាត់។ ធ្វើរួចហើយ? ដាក់ [x] ឬ 100%។
6. ពេលអ្នកវាយ ប្រអប់ "មើលជាមុន" នឹងលេចឡើងក្រោមអក្សរ។ ពិនិត្យឱ្យត្រូវ រួចចុច "បង្ហោះ ToDo" (ឬចុច Ctrl+Enter)។

**គំរូ**

```
គម្រោងបញ្ចប់ការសិក្សា
វេបសាយ
- រចនាទំព័រ Login - 80%
- [x] រៀបចំ Database
កម្មវិធីទូរស័ព្ទ
- សាងសង់ទំព័រដើម
```

**ខុស**

```
វេបសាយ
- រចនា 80%
```

**ត្រូវ**

```
វេបសាយ
- រចនា - 80%
```

ត្រូវមានសញ្ញា "-" មុនលេខ។ ឬសរសេរ "(80%)" ក៏បាន។

**ខុស**

```
វេបសាយ
- រចនា 80% រួចសរសេរបន្ត
```

**ត្រូវ**

```
វេបសាយ
- រចនាបន្ត - 80%
```

ភាគរយត្រូវនៅចុងបំផុតនៃបន្ទាត់ ទើបប្រព័ន្ធអាន។

**ខុស**

```
វេបសាយ
- រចនា, សរសេរ, តេស្ត
```

**ត្រូវ**

```
វេបសាយ
- រចនា
- សរសេរ
- តេស្ត
```

មួយបន្ទាត់ ក្នុងមួយកិច្ចការ ទើបធីក និងគិតភាគរយបាន។

> **ចំណាំ:** លេខរៀង "1." "2." ក៏ត្រូវបានអានជាកិច្ចការដែរ។

> **ចំណាំ:** ភាគរយនៃ ToDo = មធ្យមភាគនៃកិច្ចការទាំងអស់ (ធ្វើរួច = ១០០%)។

<a id="fix"></a>
## 3. ខុស? កែបាន

អ្នកអាចកែ ToDo ដែលបានបង្ហោះ។ មិនបាច់លុបហើយសរសេរថ្មីទេ។

1. ចុចរូបខ្មៅដៃ នៅជ្រុងខាងស្តាំលើនៃ ToDo របស់អ្នក (នៅក្នុងទំព័រ "ToDo ប្រចាំថ្ងៃ")។
2. កែអត្ថបទ មើលលទ្ធផលក្នុង "មើលជាមុន" រួចចុច "រក្សាទុក"។
3. កិច្ចការដែលអ្នកបានធីករួច នៅតែធីក ប្រសិនបើអត្ថបទរបស់វាមិនប្តូរ។
4. ចង់ធីក ឬដកធីក? ចុចលើកិច្ចការនោះក្នុងបញ្ជី។
5. ធីកគ្រប់កិច្ចការ ToDo នឹងរួចដោយស្វ័យប្រវត្តិ។ ឬចុច "បញ្ជាក់ថាបានធ្វើរួច" ដើម្បីឱ្យប្រធានក្រុមមកត្រួតពិនិត្យ។

> **ចំណាំ:** ពេលប្រធានក្រុមអនុម័តហើយ ToDo ត្រូវចាក់សោ គ្មាននរណាកែបានទេ។ ប្រធានក្រុមអាចចុច "បើកឡើងវិញដើម្បីកែ" ប្រសិនបើត្រូវកែ។

> **ចំណាំ:** ចង់លុបទាំងមូល? ចុចរូបធុងសំរាម។

## 4. កិច្ចការដែលបានចាត់ឱ្យ

ប្រធានក្រុមចាត់កិច្ចការឱ្យអ្នក ហើយអ្នកប្រាប់ថាធ្វើបានប៉ុន្មាន។

1. បើកផ្ទាំង "កិច្ចការ" ដើម្បីឃើញកិច្ចការរបស់អ្នក និងថ្ងៃកំណត់។
2. ចុច "ចាប់ផ្តើម" ពេលអ្នកចាប់ផ្តើមធ្វើ។
3. រំកិលរបារ "វឌ្ឍនភាព" ឬចុច 25% 50% 75%។ ប្រព័ន្ធរក្សាទុកឱ្យដោយខ្លួនឯង មិនបាច់ចុចរក្សាទុកទេ។
4. ធ្វើរួច? ចុច "រួចរាល់" (១០០%) ឬ "ធ្វើរួច ផ្ញើឱ្យពិនិត្យ"។ កិច្ចការនឹងទៅរង់ចាំប្រធានក្រុមត្រួតពិនិត្យ។
5. រង់ចាំប្រធានក្រុមពិនិត្យ។ បើត្រឹមត្រូវ គាត់អនុម័ត ហើយកិច្ចការត្រូវចាក់សោ។ បើមិនទាន់ត្រូវ គាត់ចុច "ស្នើសុំកែ" ជាមួយមូលហេតុ ហើយកិច្ចការត្រឡប់ទៅ "កំពុងធ្វើ" ហើយអ្នកទទួលដំណឹង។ កែរួចផ្ញើម្ដងទៀត។

> **ចំណាំ:** ពណ៌ក្រហម = ហួសកំណត់។ សួរសំណួរដោយដាក់មតិយោបល់ក្នុងកិច្ចការ។

> **ចំណាំ:** ចង់ដឹងថាថ្ងៃនេះមានអ្វីត្រូវធ្វើ? នៅទំព័រ "ទិដ្ឋភាពទូទៅ" មានជួរ "ថ្ងៃនេះ" បង្ហាញចំនួនកិច្ចការ "ខ្ញុំម្នាក់ឯង" "ខ្ញុំរួមក្រុម" និង "ហួសកំណត់"។ ចុចលើវា (ឬលើកាតខាងក្រោម) ដើម្បីបើកទំព័រដែលត្រងរួចហើយ។ ទំព័រ "កិច្ចការ" និង "ToDo ប្រចាំថ្ងៃ" មានតម្រងដូចគ្នា៖ ទាំងអស់/ខ្ញុំម្នាក់ឯង គ្រប់ពេល/ថ្ងៃនេះ/ជ្រើសថ្ងៃ និងស្ថានភាព។

> **ចំណាំ:** ពិពណ៌នាវែង? ចុច "បង្ហាញបន្ថែម" ក្រោមកិច្ចការ ដើម្បីមើលទាំងអស់ (ឧទាហរណ៍ បញ្ជីអ្វីដែលត្រូវដំឡើង)។

## 5. កិច្ចការរួម (ទាំងអស់គ្នា)

កិច្ចការតែមួយ ដែលសមាជិកម្នាក់ៗត្រូវធ្វើ ឧទាហរណ៍ "ដំឡើងកម្មវិធី"។

1. ប្រធានក្រុមជ្រើស "ទាំងអស់គ្នា" ឬ "ជ្រើសរើស" ពេលកំណត់កិច្ចការថ្មី។
2. កាតតែមួយបង្ហាញវឌ្ឍនភាពរួម (មធ្យមភាគ) និងផ្នែករបស់ម្នាក់ៗ។
3. អ្នករំកិលបានតែវឌ្ឍនភាពរបស់អ្នកផ្ទាល់។ ប្រធានក្រុមកែបានរបស់គ្រប់គ្នា។
4. ចុច "មើលជាកិច្ចការនីមួយៗ" ដើម្បីមើលចំណាំ មតិយោបល់ និងថ្ងៃកំណត់របស់ម្នាក់ៗ។

<a id="talk"></a>
## 6. មតិយោបល់ និងប្រតិកម្ម

1. ចុច "មតិយោបល់" ក្រោមកិច្ចការ ឬ ToDo រួចសរសេរក្នុងប្រអប់។ ចុចព្រួញនៅខាងស្តាំ (ឬ Ctrl+Enter) ដើម្បីផ្ញើ។
2. កែ ឬលុបមតិរបស់អ្នកបាន។ ប្រធានក្រុមលុបមតិអ្នកដទៃបាន តែកែមិនបាន។
3. ចុចរូបញញឹមក្បែរ ToDo ដើម្បីដាក់ប្រតិកម្ម។ ចុចម្តងទៀតដើម្បីដកចេញ។
4. រូបកណ្ដឹងខាងលើ ប្រាប់ពីការងារ និងមតិថ្មី។

## 7. Streak និងការ Poke

Streak គឺចំនួនថ្ងៃជាប់គ្នាដែលអ្នកបង្ហោះ ToDo ប្រចាំថ្ងៃ។ វាជួយឱ្យអ្នកមានទម្លាប់ ហើយក្រុមឃើញថាអ្នកណាខ្នះខ្នែង។

1. បង្ហោះ ToDo យ៉ាងតិច ១ ដងក្នុងមួយថ្ងៃ (ម៉ោងកម្ពុជា)។ ថ្ងៃនោះរាប់ ហើយ Streak កើនម្តង។
2. Streak របស់អ្នកបង្ហាញលើប្រអប់បង្ហោះ (🔥 ៥ ថ្ងៃជាប់គ្នា)។ ចំណាត់ថ្នាក់ក្រុមនៅទំព័រ "ទិដ្ឋភាពទូទៅ"។
3. ខាន ១ ថ្ងៃពេញ Streak ត្រឡប់ទៅ ០។ ប៉ុន្តែបើថ្ងៃនេះមិនទាន់ផុត អ្នកនៅមានពេលបង្ហោះដើម្បីរក្សា។
4. ឃើញសមាជិកមិនទាន់បង្ហោះថ្ងៃនេះ? ចុច "Poke" ក្បែរឈ្មោះគាត់។ គាត់ទទួលការជូនដំណឹង (និងសារ Telegram បើបានភ្ជាប់)។
5. អ្នក Poke មនុស្សតែមួយបាន ១ ដងក្នុងមួយថ្ងៃ។ ពេលគាត់បង្ហោះរួច ប៊ូតុង Poke បាត់។
6. ចង់ទទួលការ Poke នៅ Telegram? បើក "ការកំណត់របស់ខ្ញុំ" ចុច "ភ្ជាប់ Telegram" រួចចុច Start ក្នុង Telegram (បើប្រព័ន្ធបើកមុខងារនេះ)។

> **ចំណាំ:** Streak រាប់តាមថ្ងៃដែលបង្ហោះពិតប្រាកដ។ អ្នកមើលមិនមាន Streak ទេ។

## 8. សម្រាប់ប្រធានក្រុម

1. បង្កើតក្រុម រួចបន្ថែមសមាជិក ("បន្ថែមសមាជិក")។ ពាក្យសម្ងាត់បណ្តោះអាសន្នបង្ហាញតែម្តង ដូច្នេះចម្លងវាភ្លាម។
2. ចាត់កិច្ចការ៖ ប៊ូតុង "កំណត់កិច្ចការថ្មី"។ ជ្រើសម្នាក់ ជ្រើសរើស ឬទាំងអស់គ្នា។
3. មានកិច្ចការច្រើន? ចុច "នាំចូលកិច្ចការ" នៅទំព័រ "កិច្ចការ" រួចចម្លងតារាងពី Google Sheets ឬ Excel មកដាក់ (ឬជ្រើសឯកសារ CSV)។ ១ ជួរដេក = ១ កិច្ចការ។ ត្រូវមានជួរឈរ Task title និង Due date។ ជួរផ្សេង (Module, Assign to, Members, Priority, Start date, Due time, Details) ជាជម្រើស។ ប្រព័ន្ធបង្ហាញលទ្ធផលមុននាំចូល ហើយរំលងជួរដែលមានបញ្ហា។ ចុច "ទាញយកគំរូ" ដើម្បីបានទម្រង់ត្រូវ។
4. ប្តូរថ្ងៃកំណត់ដោយចុចលើថ្ងៃ។ ប្តូរអ្នកទទួលដោយចុច "ប្តូរអ្នកទទួល"។
5. ពិនិត្យកិច្ចការដែលមានស្លាក "រង់ចាំត្រួតពិនិត្យ"៖ "អនុម័ត" ឬ "ស្នើសុំកែ" (ត្រូវសរសេរមូលហេតុ)។ មានច្រើន? ចុច "អនុម័តទាំងអស់" ដើម្បីអនុម័តតែម្ដង។ ពេលអនុម័តរួច វាត្រូវចាក់សោ។ ចង់កែ? ចុច "បើកឡើងវិញដើម្បីកែ"។
6. ចង់កែចំណងជើង ពិពណ៌នា ប្រភេទ ឬភាពសំខាន់? ចុចរូបខ្មៅដៃលើកាតកិច្ចការ។ កិច្ចការរួមនឹងប្ដូរសម្រាប់មនុស្សគ្រប់គ្នា។ ចុច "របៀបដំណើរការកិច្ចការ" នៅទំព័រកិច្ចការ ដើម្បីមើលក្បួនទាំងអស់។
7. បើកផ្ទាំង "របាយការណ៍" រួចចុច "បោះពុម្ព / PDF" ដើម្បីទទួលបានសេចក្តីសង្ខេបបង្ហាញគ្រូ។

## 9. បញ្ហាញឹកញាប់

**ភ្លេចពាក្យសម្ងាត់?**

ប្រាប់ប្រធានក្រុម។ គាត់បង្កើតពាក្យសម្ងាត់បណ្តោះអាសន្នថ្មីឱ្យអ្នក។

**ចូលមិនបាន?**

ពិនិត្យអ៊ីមែល ឬឈ្មោះអ្នកប្រើ និងពាក្យសម្ងាត់ (មើលអក្សរធំតូច)។ បើនៅតែមិនបាន ប្រាប់ប្រធានក្រុម។

**មិនអាចសរសេរ ឬកែអ្វីទេ?**

អ្នកប្រហែលជា "អ្នកមើល" ដែលអានបានតែប៉ុណ្ណោះ។ ឬគណនីប្រធានក្រុមផុតកំណត់ ក្រុមក្លាយជាមើលតែប៉ុណ្ណោះ។

**ToDo ត្រូវបានអនុម័តហើយ ចង់កែ?**

ប្រាប់ប្រធានក្រុម។ ប្រធានក្រុមត្រូវចុច "បើកឡើងវិញដើម្បីកែ" ជាមុនសិន ទើបអ្នកកែបាន។

**ភាគរយ ToDo ខុស?**

សរសេរ "- 80%" នៅចុងបន្ទាត់ ហើយមើល "មើលជាមុន" មុនបង្ហោះ។
