# មាតិកាបើកដំណើរការ LeaderSync (សម្រាប់និស្សិត)

> ជំនួស `[តំណ]` ដោយតំណវេបសាយរបស់អ្នក។ កុំប្រកាសអ្វីដែលអ្នកមិនទាន់ផ្តល់ជាក់ស្តែង
> (ជាពិសេសបន្ទាត់ដែលមានសញ្ញា ⚠️ ដូចជា "១ ខែឥតគិតថ្លៃ" និងតម្លៃ)។
> ទាំងអស់ជាសម្មតិកម្មត្រូវសាកល្បង។ ផ្លាស់ប្តូរពាក្យឱ្យត្រូវនឹងរបៀបនិយាយរបស់អ្នក។

---

## ផ្នែក ១៖ ស្គ្រីបវីដេអូខ្លី (TikTok / Facebook Reels / Telegram) — ៣០ វិនាទី

គោលការណ៍៖ ចាប់ផ្តើមដោយបញ្ហាដែលនិស្សិតស្គាល់ (៣ វិនាទីដំបូងសំខាន់បំផុត) កុំចាប់ផ្តើមដោយឈ្មោះកម្មវិធី។
វីដេអូទាំងអស់បញ្ចប់ដោយ **ប៊ូតុង "ទស្សនកិច្ច"** (មិនបាច់ចុះឈ្មោះ) មិនមែនការលក់ដោយផ្ទាល់ទេ។

### វីដេអូ ១ — "សមាជិកដែលបាត់ខ្លួន"
| វិនាទី | ទិដ្ឋភាព | សំឡេង / អក្សរលើអេក្រង់ |
|---|---|---|
| 0–3 | ទូរសព្ទបង្ហាញ Telegram group ដែលគ្មាននរណាឆ្លើយ | "ថ្ងៃនេះជិតផុតកំណត់ហើយ... សមាជិកទៅណាអស់?" |
| 3–10 | ថតជិតមុខប្រធានក្រុមដែលធុញទ្រាន់ កំពុងវាយក្តារចុចម្នាក់ឯង | "ប្រធានក្រុមធ្វើម្នាក់ឯងទៀតហើយ" |
| 10–22 | បង្ហាញអេក្រង់ LeaderSync (ទស្សនកិច្ច)៖ បញ្ជីកិច្ចការ មានឈ្មោះ និងស្ថានភាព | "ឥឡូវដឹងភ្លាម អ្នកណាធ្វើអី អ្នកណាមិនទាន់ធ្វើ" |
| 22–30 | ចុចប៊ូតុង "ទស្សនកិច្ច" | "សាកល្បងមើលឥតគិតថ្លៃ មិនបាច់ចុះឈ្មោះ។ តំណក្នុង bio" |

### វីដេអូ ២ — "គ្រូសួរថាអ្នកណាធ្វើផ្នែកណា?"
| វិនាទី | ទិដ្ឋភាព | សំឡេង / អក្សរលើអេក្រង់ |
|---|---|---|
| 0–4 | គ្រូសួរក្នុងថ្នាក់៖ "ក្រុមនេះអ្នកណាធ្វើផ្នែកណា?" ក្រុមស្ងៀមស្ងាត់មើលមុខគ្នា | "ពេលគ្រូសួរថាអ្នកណាធ្វើអី..." |
| 4–12 | បង្ហាញប្រធានក្រុមដែលព្រួយបារម្ភ | "ចាំអត់? ខ្ញុំក៏ភ្លេចដែរ" |
| 12–24 | បង្ហាញ **របាយការណ៍សង្ខេប** នៅក្នុងកម្មវិធី (ទិន្នន័យគំរូ) | "ទាញរបាយការណ៍ ១ ចុច បង្ហាញគ្រូបានភ្លាម" |
| 24–30 | ប៊ូតុងទស្សនកិច្ច | "សាកល្បងមើល តំណក្នុង bio" |

### វីដេអូ ៣ — "ភ្លេចថាអ្នកណាសន្យាអ្វី"
| វិនាទី | ទិដ្ឋភាព | សំឡេង / អក្សរលើអេក្រង់ |
|---|---|---|
| 0–4 | រមូរសារ Telegram រាប់រយ ស្វែងរកសារចាស់ | "ស្វែងរកសារ ដែលគេសន្យាធ្វើ... ក្នុងចំណោមសារ ៥០០" |
| 4–14 | បង្ហាញ **ជួងជូនដំណឹង** ក្នុងកម្មវិធី៖ "កិច្ចការថ្មីជូនអ្នក", "ជិតដល់ថ្ងៃកំណត់" | "កម្មវិធីរំលឹកអ្នកដោយខ្លួនឯង" |
| 14–24 | បង្ហាញ **មតិយោបល់** ក្នុងកិច្ចការមួយ | "ពិភាក្សាក្នុងកិច្ចការនីមួយៗ មិនច្របូកច្របល់" |
| 24–30 | ប៊ូតុងទស្សនកិច្ច | "ប្រើបានលើទូរសព្ទ ភាសាខ្មែរ។ សាកល្បងឥតគិតថ្លៃ" |

**ពាក្យសម្គាល់៖** ថត screen recording ពី "ទស្សនកិច្ច" (ទិន្នន័យគំរូ) ដូច្នេះមិនបង្ហាញទិន្នន័យពិតរបស់នរណាទេ។
**ឃ្លាចុងសម្រាប់ caption៖** `កិច្ចការក្រុម ដោយមិនមានជម្លោះ`
**Hashtag ស្នើ៖** `#និស្សិតខ្មែរ #កិច្ចការក្រុម #LeaderSync` (សាកល្បង និងប្តូរតាមអ្វីដែលនិស្សិតពិតប្រើ)

---

## ផ្នែក ២៖ ប្រកាសសម្រាប់ Telegram / Facebook

### ក. សម្រាប់ group ថ្នាក់ (ខ្លី ងាយអាន)
```
ក្រុមអ្នកធ្វើគម្រោងរួមគ្នាមែនទេ? 👇

តើធ្លាប់មានបញ្ហាទាំងនេះអត់?
• សមាជិកខ្លះមិនធ្វើអ្វីសោះ
• មិនដឹងថាអ្នកណាធ្វើអ្វី ដល់ណាហើយ
• ជិតផុតកំណត់ទើបដឹងថាមានអ្វីមិនទាន់រួច

LeaderSync ជួយឱ្យអ្នកឃើញអ្វីទាំងអស់នៅមួយកន្លែង៖ កិច្ចការ ថ្ងៃកំណត់ របាយការណ៍ប្រចាំថ្ងៃ និងជួងជូនដំណឹង។
ជាភាសាខ្មែរ ប្រើលើទូរសព្ទបាន។

👉 សាកល្បងមើលមុនពេលសម្រេចចិត្ត (មិនបាច់ចុះឈ្មោះ)៖ [តំណ]
```

### ខ. សម្រាប់ប្រធានក្រុម (ផ្ទាល់ខ្លួន / DM)
```
សួស្តី [ឈ្មោះ]! ខ្ញុំឃើញអ្នកជាប្រធានក្រុមគម្រោង [ឈ្មោះគម្រោង/ថ្នាក់]។

ខ្ញុំកំពុងបង្កើតកម្មវិធីមួយឈ្មោះ LeaderSync ដើម្បីជួយប្រធានក្រុមឱ្យដឹងថាអ្នកណាធ្វើអ្វី
ដោយមិនចាំបាច់ដេញសួរក្នុង Telegram។

អ្នកអាចសាកល្បងមើលមុនបាន មិនបាច់ចុះឈ្មោះ៖ [តំណ]
បើអ្នកចូលចិត្ត ខ្ញុំអាចជួយបង្កើតក្រុមឱ្យអ្នក ហើយអ្នកប្រាប់ខ្ញុំថាអ្វីល្អ អ្វីមិនល្អ ជាការឆ្លើយតប។
```
⚠️ បើអ្នកផ្តល់ការប្រើឥតគិតថ្លៃ ១ ខែ បន្ថែមបន្ទាត់៖ `ក្រុមដំបូងៗ ប្រើឥតគិតថ្លៃ ១ ខែ។` (ហើយបើកប្រអប់ "ក្រុមដំបូងៗ ប្រើឥតគិតថ្លៃ ១ ខែ" ក្នុង Admin → កំណត់ទំព័រណែនាំ ផង)

### គ. សម្រាប់គ្រូបង្រៀន
```
សួស្តីលោកគ្រូ/អ្នកគ្រូ។
ខ្ញុំជាអ្នកបង្កើតកម្មវិធី LeaderSync ដែលជួយនិស្សិតតាមដានកិច្ចការក្រុម។

លោកគ្រូអាចចូលជា "អ្នកមើល" (អានបានតែប៉ុណ្ណោះ) ដើម្បីឃើញថាអ្នកណាធ្វើអ្វីក្នុងក្រុមនីមួយៗ
ឬនិស្សិតអាចទាញរបាយការណ៍សង្ខេបមកបង្ហាញលោកគ្រូ។

ទស្សនកិច្ចដោយមិនបាច់ចុះឈ្មោះ៖ [តំណ]
ខ្ញុំរីករាយទទួលមតិកែលម្អ។
```

### ឃ. សម្រាប់ Ambassador (ប្រធានថ្នាក់/ក្លឹប)
```
ខ្ញុំចង់ឱ្យអ្នកសាកល្បង LeaderSync ជាមួយក្រុមរបស់អ្នក ជាអ្នកសាកល្បងមុនគេ។
ប្រសិនបើអ្នកចូលចិត្ត ហើយណែនាំមិត្តរួមថ្នាក់ ខ្ញុំនឹង[ផ្តល់អ្វីជាក់លាក់៖ ឧ. ខែប្រើឥតគិតថ្លៃ]។
```
⚠️ បំពេញអ្វីដែលអ្នកពិតជាអាចផ្តល់ បើមិនប្រាកដ សូមកុំសន្យា។

## ផ្នែក ៣៖ សំណួរសម្ភាសអ្នកសាកល្បង (ត្រូវសួរ ៥ ក្រុមដំបូង)

១. តើអ្នកមើលឃើញអ្វីមុនគេ ពេលបើកកម្មវិធី? (ដើម្បីដឹងថាអ្វីច្បាស់/មិនច្បាស់)
២. អ្វីដែលអ្នកចូលចិត្តបំផុត? អ្វីដែលពិបាកយល់?
៣. តើក្រុមអ្នកបានប្រើវារៀងរាល់ថ្ងៃទេ? ហេតុអ្វី/ហេតុអ្វីមិន?
៤. តើអ្នកធ្លាប់ប្រើអ្វីផ្សេងសម្រាប់បញ្ហានេះ? (Telegram, Google Sheets…) ហេតុអ្វីបានជាប្តូរ/មិនប្តូរ?
៥. **បើត្រូវបង់ប្រាក់ តើតម្លៃប៉ុន្មានថោកពេកដែលអ្នកសង្ស័យ? ប៉ុន្មានសមរម្យ? ប៉ុន្មានថ្លៃពេក?**
   (សំណួរតម្លៃ ត្រូវសួរបែបបីដំណាក់កាល ដើម្បីរកជួរតម្លៃពិត)
៦. តើអ្នកនឹងណែនាំមិត្តរួមថ្នាក់ទេ? ពេលណា?
៧. តើអ្នកអនុញ្ញាតឱ្យយើងដាក់មតិរបស់អ្នកជាសក្ខីកម្មទេ? (សុំការអនុញ្ញាតជាមុន)

## ផ្នែក ៤៖ ព្រឹត្តិការណ៍ និងពេលវេលា
- **ពេលចាប់ផ្តើមឆមាស** គឺពេលដ៏ល្អបំផុត ព្រោះមានគម្រោងក្រុមថ្មី។ ជៀសវាងពេលប្រឡង។
- ក្លឹប, hackathon, ការប្រកួត startup ជាកន្លែងមានក្រុមធ្វើការដោយធម្មជាតិ។
- វាស់៖ ចំនួនអ្នកទាក់ទង Telegram ក្នុងមួយសប្តាហ៍ និងចំនួនក្រុមដែលនៅប្រើក្រោយ ៧ ថ្ងៃ។
